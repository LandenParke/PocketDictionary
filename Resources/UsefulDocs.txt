For binding ports to WSL
========================

winget install usbipd if not already installed

run powershell in administrator and do usbipd list
note the bus id for whatever is labeled "Silicon Lab CP210X ...."

run usbipd bind --busid BUSID
then usbipd attach --wsl --busid BUSID
